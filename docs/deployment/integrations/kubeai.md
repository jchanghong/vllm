# KubeAI

[KubeAI](https://github.com/substratusai/kubeai) 是一个 Kubernetes 算子，使您能够在 Kubernetes 上部署和管理 AI 模型。它提供了一种简单且可扩展的方式在生产环境中部署 vLLM。零外部依赖，开箱即用地提供了从零扩缩容、基于负载的自动扩缩、模型缓存等功能。

请参阅安装指南以获取特定环境的说明：

- [任意 Kubernetes 集群](https://www.kubeai.org/installation/any/)
- [AKS](https://www.kubeai.org/installation/aks/)
- [EKS](https://www.kubeai.org/installation/eks/)
- [GKE](https://www.kubeai.org/installation/gke/)

安装 KubeAI 后，您可以
[配置文本生成模型](https://www.kubeai.org/how-to/configure-text-generation-models/)
，使用 vLLM 作为后端。
