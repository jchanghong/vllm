# NVIDIA Dynamo

[NVIDIA Dynamo](https://github.com/ai-dynamo/dynamo) 是一个面向分布式 LLM 推理的开源框架，可以在 Kubernetes 上运行 vLLM，并支持灵活的服务架构（例如聚合式/分离式、可选的路由器/规划器）。

有关 Kubernetes 部署说明和示例（包括 vLLM），请参阅 [在 Kubernetes 上部署 Dynamo](https://github.com/ai-dynamo/dynamo/blob/main/docs/kubernetes/README.md) 指南。

背景阅读：InfoQ 新闻报道 — [NVIDIA Dynamo 简化了 LLM 推理的 Kubernetes 部署](https://www.infoq.com/news/2025/12/nvidia-dynamo-kubernetes/)。
