# llm-d

vLLM 可以与 [llm-d](https://github.com/llm-d/llm-d) 一起部署，llm-d 是一个 Kubernetes 原生的分布式推理服务栈，为任何人大规模提供生成式 AI 模型提供了清晰的路径。它有助于在大多数硬件加速器和基础设施提供商上，为主要 OSS 模型实现最快的"达到最先进（SOTA）性能的时间"。

您可以直接按照[官方指南](https://llm-d.ai/docs/guides)使用 vLLM 与 llm-d，或通过 [KServe 的 LLMInferenceService](https://kserve.github.io/website/docs/model-serving/generative-inference/llmisvc/llmisvc-overview) 使用。
